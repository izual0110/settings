Среда разработки.
Одной командой.

Выберите Linux, языки и инструменты. Скопируйте команду в терминал проекта — Bash соберёт вашу .devcontainer.

01 Операционная система

Один контейнер — один Linux.

Версия образа

Релизы фиксируются в генераторе. latest — плавающий тег издателя образа, он может меняться между сборками.

02 Языки

Можно выбрать несколько — или оставить только Linux.

Версии языков зависят от репозиториев выбранного Linux. Генератор не устанавливает SDK на ваш компьютер.

03 Инструменты

Bash, Git, curl, CA-сертификаты, tar, gzip, find и ps уже включены.

Docker подключает /var/run/docker.sock. Доступ к сокету даёт контейнеру управление Docker-демоном хоста; включайте только для доверенных проектов.

Docker-сокет будет смонтирован в контейнер. На Linux это может дать доступ с правами root к хосту. Для Ubuntu 22.04 возможен fallback на Compose v1.
