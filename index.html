01 Operating system

Image version

Releases are pinned in the generator. latest is a floating tag maintained by the image publisher and may change between builds.

02 Languages

Choose multiple languages — or stick with just Linux.

Java version
Java build tools

Java: 25 LTS or 27 from Eclipse Temurin images (Docker Hub), using musl-compatible images on Alpine. Optional Maven and Gradle use your selected JDK. Clojure CLI 1.12.6.1673: the official installer from GitHub, rlwrap, and your selected Java version (25 LTS by default). PHP and Go come from Linux repositories. Network access is required when building the container; no SDKs are installed on the host.

03 Tools

Bash, Git, curl, CA certificates, tar, gzip, find, and ps are already included.

Claude Code and Codex are installed only inside the container. Authentication is required after startup; service usage depends on your plan. Host keys and settings are not copied.

Docker mounts /var/run/docker.sock. Socket access lets the container control the host's Docker daemon; enable it only for trusted projects.

The Docker socket will be mounted inside the container. On Linux, this may grant root-level access to the host. Ubuntu 22.04 may fall back to Compose v1.
